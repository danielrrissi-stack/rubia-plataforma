# Receita e plano alimentar em PDF — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Botão "Baixar PDF" na receita e no plano alimentar, gerando um arquivo PDF real no servidor com o mesmo conteúdo da página de impressão.

**Architecture:** Dompdf 3.1.6 versionado em `lib/dompdf/`; um serviço `App\Pdf\PdfRenderer` monta o documento HTML (CSS próprio embutido, lido de `app/Pdf/pdf.css`) e devolve os bytes do PDF; `Response::pdf()` entrega como download. O corpo da receita e do plano vira um parcial compartilhado entre a página de impressão e o PDF.

**Tech Stack:** PHP 8.1+ (strict_types), Dompdf 3.1.6 (sem Composer em produção), PHPUnit 11 (`tools/phpunit.phar`), MariaDB local / MySQL 5.7 na hospedagem.

**Spec:** `docs/superpowers/specs/2026-11-18-pdf-receita-plano-design.md`

- Test: `tests/Unit/PdfRendererTest.php`, `tests/Unit/PdfFilenameTest.php`, `tests/Unit/RequirementsTest.php` (se já testar a lista de extensões)

**Interfaces — Produces:**
- `App\Pdf\PdfRenderer::__construct(string $libDir, string $cacheDir)`
- `PdfRenderer::document(string $title, string $bodyHtml): string` — HTML completo (`<!doctype html>`, `<meta charset="utf-8">`, `<title>` escapado, `<style>` com o conteúdo de `pdf.css`, `<body>` com `$bodyHtml` sem alterar).
- `PdfRenderer::render(string $title, string $bodyHtml): string` — bytes do PDF (carrega `lib/dompdf/autoload.inc.php` só aqui, sob demanda).
- `App\Pdf\PdfFilename::make(string $prefix, string $name, string $dateYmd): string` → `make('Receita', 'Maria Silva', '2026-11-18') === 'Receita - Maria Silva - 18-11-2026.pdf'`; remove `\ / : * ? " < > |` e caracteres de controle, junta espaços repetidos, corta o nome em 80 caracteres (mb).
- `Response::pdf(string $bytes, string $downloadName): Response` — cabeçalhos da Global Constraints; fallback ASCII = nome com cada caractere fora de `\x20-\x7E` trocado por `_`.
- `Container::pdf(): PdfRenderer` com `libDir = APP_ROOT . '/lib/dompdf'` e `cacheDir = <storage_path>/cache/dompdf` (mesmo padrão `Config::get('storage_path', APP_ROOT . '/storage')` já usado no Container).
